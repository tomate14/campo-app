# 36 - Maquinaria: Mantenimiento offline y notificaciones avanzadas

## Descripcion
Extender la feature 09 con capacidades avanzadas que quedaron fuera del core operativo: disponibilidad offline real, notificaciones automaticas persistentes y sincronizacion robusta de mantenimiento.

## Pendientes
- Modo offline real para consultar planes, programaciones e historial tecnico.
- Cola local de intervenciones registradas sin conexion.
- Sincronizacion con resolucion de conflictos al recuperar conectividad.
- Notificaciones automaticas por vencimiento de mantenimiento.
- Recordatorios configurables por fecha, horometro y prioridad.
- Integracion futura con mobile para avisos push.
- Auditoria de entrega, lectura y resolucion de alertas.

## Dependencias
- Feature 08 - Maquinaria: Inventario y Control
- Feature 09 - Maquinaria: Mantenimiento Preventivo
- Feature 24 - Sincronizacion Offline-First
- Mobile / notificaciones push
